# Contributing

Thank you for helping. You do not need to write code. Read [MODUS_OPERANDI.md](MODUS_OPERANDI.md) first.

## Ways to help
- `nd-review`: use a build and tell us what felt hard or noisy.
- `design`: colours, icons, spacing, wording.
- `docs`: plain-language guides.
- `translation`: translate the app text.
- `good first issue`: small, clear code tasks.

## Code changes
1. Open an issue first for anything bigger than a small fix.
2. Fork, make a branch, make one change.
3. Run `node scripts/check-repo.mjs`.
4. Open a pull request. Say what changed and why. Keep it short.

## Writing style
Plain words. Short sentences. One idea per paragraph. No jokes at the user's expense.
