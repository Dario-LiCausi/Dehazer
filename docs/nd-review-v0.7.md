# nd-review request: v0.7 Honey and pine

Label: `nd-review`. Please read this before you try the app. It takes about 10 minutes.

## What moves
Nothing moves. Every button, box and link is in the same place and the same order as v0.6. List order is the same. Motion is off.

## What changes
- Default colours and default font (frozen items in LAYOUT-FREEZE.md).
- Card shapes: no left bar, soft tint, one shadow.
- Wording: shorter and kinder. Main button text is the same (Task, Cue, Save task, Save cue, Done, Not now, Drop).

## Why
A user said v0.6 felt cold and clinical.

## Keep the old look
Settings, Look, "Old warm look (v0.6)". It stays for one release. Plain also stays.

## Questions for reviewers
1. Does the new look feel calmer, the same, or more tiring than v0.6?
2. Can you find every button without looking for it?
3. Is any word unclear, or does any word feel like pressure?
4. Is any text hard to read in light, dark or at a larger text size?

Release notes ship first: the "What changed" screen appears once after the update.
